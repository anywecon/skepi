# S.K.E.P.I. v0.2.3-preview — release notes

Body of the GitHub pre-release `v0.2.3-preview` (tag on `@COMMIT12@`). The placeholders `@…@` are
filled by the release steps in `docs/release-process.md` before publishing; the hashes are also in
`SHA256SUMS.txt` on the release page. No pack release is needed: this version keeps the catalog and the

---

**Project S.K.E.P.I. Developer Preview `v0.2.3-preview`: for developers and testers. Not for emergency use.**

S.K.E.P.I. (Survival Knowledge & Emergency Pocket Intelligence) is an offline knowledge and emergency
app. It offers Wikipedia search and sealed article reading, answers built from source excerpts with an
optional on-device AI summary, maps and places for every country, emergency numbers and tools, and
sharing packs between devices. It has no accounts, analytics or telemetry.

> **Intended purpose.** S.K.E.P.I. is for general reference and education only. It is not a medical
> device and does not diagnose, treat, cure, or prevent any medical condition. Consult a healthcare
> professional for medical advice. In an emergency, call 112 or your local emergency number.

## What changed since 0.2.1-preview

A security hardening update. 0.2.2-preview was not released: in testing, its first start after an
upgrade stopped trusting map and places packs from the catalog of 0.1.x. This version contains all of its
changes and the fix; every upgrade path from a published version is now a release check. The signed
catalog (sequence 4), the packs and the emergency cards are unchanged. Each change below comes with a
regression test.

### Security

- **Packs are bound to their files.** The app used to trust an installed pack when its size was
  unchanged. It now records the file's identity (size, file id, modification and change time) and hashes
  the pack again after any change; a pack whose bytes changed loses its verified state (Android and
  Windows).
- **Packs from an earlier catalog, and revocation.** A pack that an earlier signed catalog verified stays
  verified while its bytes are unchanged, also when the current catalog lists a newer version (for
  example the Greece map and places from 0.1.x): Library shows "Verified (older catalog)", so it can be updated, and the integrity check compares it with the hash that verified it. A signed catalog
  can now revoke pack hashes; a revoked map, places or model pack is never opened again and a revoked
  Wikipedia pack becomes unverified, from the next start or right after a catalog update.
- **Android 7–10: packs in private storage.** On these versions other apps with the storage permission
  can write to the app's external folder, so packs now live in internal storage. Packs of earlier versions
  move there at the first start: the old copy is removed only after the new copy matched the signed
  catalog. Without enough free space nothing is deleted and Library explains what to do.
- **Archive identity.** A second archive that claims the identity of an open one is refused, verified
  packs open first, and the "Unverified" label is shown whenever the app cannot prove otherwise.
- **Article pages** can no longer ask the system to look up or contact other hosts in advance.
- **Windows:** malformed archive content can no longer end the app.
- **Imports** are hashed where they are installed. Release builds ignore extra data files placed in the
  content folder.
- **Nearby sharing** (Windows Station and Android host): connections that have not paired yet have their
  own small budget and time limits, so they cannot block phones that are pairing; the Android host listens
  only on the address in its QR code; the APK download page limits connections and slow readers. The
  page shows the certificate fingerprint to compare instead of calling the APK official.
- **Places database** connections cannot open other database files.
- **Downloads:** one download at a time per pack on Windows; on Android a download stops as soon as it
  exceeds the size in the signed catalog.
- **Benchmark:** the held-out runner asks for consent before opening its archive.
- **Release process:** signing accepts only the reproducible CI build of the release tag's commit.

### Fixed

- **Android 7.0–7.1:** file moves no longer use an API that exists only from Android 8, which installs
  and catalog updates relied on.

### Changed

- **The repository moved** to <https://github.com/anywecon/skepi>. Old links redirect; pack download
  addresses in the signed catalog keep working through that redirect until the next catalog update.

### Accepted advisories

Two packages keep open HIGH advisories because no usable fix exists yet. The reasons and mitigations are in
[`docs/threat-model.md`](https://github.com/anywecon/skepi/blob/v0.2.3-preview/docs/threat-model.md#dependency-risk-acceptance).

- **decode-uri-component 0.2.2**
  ([GHSA-qr28-fpjm-wq7f](https://github.com/advisories/GHSA-qr28-fpjm-wq7f), HIGH;
  [GHSA-vcc3-ghjq-m6fr](https://github.com/advisories/GHSA-vcc3-ghjq-m6fr), MODERATE): slow decoding of
  malformed input. It **ships in the Android app**, through `expo-router`. The fixed release breaks route
  parameters under Metro. It is reachable only through links of at most 2048 characters, because of the
  guard above.
- **zod 3.25.76** ([GHSA-mrhx-c7xc-m3w5](https://github.com/advisories/GHSA-mrhx-c7xc-m3w5), HIGH): memory
  exhaustion on a very large array. It is in build and development tooling only (`@expo/cli`), and is not
  in the Android or Windows app.

## Known limitations

- Developer Preview: tested on a Samsung Galaxy S23 and Windows 11 x64 only; the Android 7–10 storage
  move was tested on Android 7.0 and 10 emulators. English only.
- **No macOS build.** The macOS desktop app is built in CI only, and its map has not been run on WKWebView
  with MapLibre 6.
- **iOS: downloads are not supported yet** (Maps & places shows the countries; packs are provisioned or
  imported).
- **Several countries at once** were tested on the S23 with up to 3 map packs (Cyprus, Greece and
  Japan's Kanto part) together; phones with less memory and five or more countries are not measured.
- Some parts of countries with overseas territories span areas far apart (for example France's
  Réunion with Provence): "show on map" frames the whole part.
- Emergency numbers: official sources for 35 countries only; elsewhere "112 — check the local number".
- Source excerpts are shown verbatim: a wrong or misleading sentence in a pack is shown as written.
- AI summaries can be wrong: check the cited excerpt. Emergency and medical questions get no AI summary.
- Windows installers are unsigned; no automatic updates.
