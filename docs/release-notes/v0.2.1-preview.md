# S.K.E.P.I. v0.2.1-preview — release notes

Body of the GitHub pre-release `v0.2.1-preview` (tag on `@COMMIT12@`). The placeholders `@…@` are
filled by the release steps in `docs/release-process.md` before publishing; the hashes are also in
`SHA256SUMS.txt` on the release page. No pack release is needed: this version keeps the catalog and the
packs of 0.2.0-preview.

---

**Project S.K.E.P.I. Developer Preview `v0.2.1-preview`: for developers and testers. Not for emergency use.**

S.K.E.P.I. (Survival Knowledge & Emergency Pocket Intelligence) is an offline knowledge and emergency
app. It offers Wikipedia search and sealed article reading, answers built from source excerpts with an
optional on-device AI summary, maps and places for every country, emergency numbers and tools, and
sharing packs between devices. It has no accounts, analytics or telemetry.

> **Intended purpose.** S.K.E.P.I. is for general reference and education only. It is not a medical
> device and does not diagnose, treat, cure, or prevent any medical condition. Consult a healthcare
> professional for medical advice. In an emergency, call 112 or your local emergency number.

## Verify before installing

```sh
sha256sum -c SHA256SUMS.txt                       # Linux / macOS / Git Bash
Get-FileHash .\SKEPI_0.2.1-preview_x64-setup.exe  # Windows PowerShell; compare with SHA256SUMS.txt
apksigner verify --print-certs skepi-0.2.1-preview-arm64.apk
```

## What changed since 0.2.0-preview

A security and fixes update. The signed catalog (sequence 4), the packs and the emergency cards are
unchanged.

### Security

- **Windows: map library XSS fixed.** maplibre-gl 5.24.0 → 6.16.0 fixes
  [GHSA-jrc7-96c5-q579](https://github.com/advisories/GHSA-jrc7-96c5-q579) (critical): a crafted attribution
  string could get past the library's HTML sanitizer. The app's map style is bundled and its content
  security policy already refused inline scripts. The map worker now also loads from the app itself, and
  the policy no longer allows `blob:` workers.
- **Android: deep link length guard.** A crafted `skepi://` link, once opened, could stall the app and with
  it every screen, including the emergency cards. Links longer than 2048 characters are now ignored before
  they are parsed: the app stays on the screen it was on, or opens the start screen.

### Fixed

- **Windows: emergency points and the selected place on the map.** The emergency points and the highlight
  of a selected place were never drawn, and clicking a point did nothing. Both now work.

### Changed

- **Windows:** the map now needs WebGL2; without it the map screen shows an error instead of a blank map.
  Some street labels are placed differently at high zoom (MapLibre 6).
- **Dependency updates,** in tools and the build only: simple-git 4, node-forge 1.4.1, uuid 11 and zod 4.6.7
  through scoped overrides. Windows app: rustls 0.23.46, tokio 1.53.3, rustls-webpki 0.103.16,
  webpki-root-certs 1.0.11.

### Accepted advisories

Two packages keep open HIGH advisories because no usable fix exists yet. The reasons and mitigations are in
[`docs/threat-model.md`](https://github.com/Fiouri/skepi/blob/v0.2.1-preview/docs/threat-model.md#dependency-risk-acceptance).

- **decode-uri-component 0.2.2**
  ([GHSA-qr28-fpjm-wq7f](https://github.com/advisories/GHSA-qr28-fpjm-wq7f), HIGH;
  [GHSA-vcc3-ghjq-m6fr](https://github.com/advisories/GHSA-vcc3-ghjq-m6fr), MODERATE): slow decoding of
  malformed input. It **ships in the Android app**, through `expo-router`. The fixed release breaks route
  parameters under Metro. It is reachable only through links of at most 2048 characters, because of the
  guard above.
- **zod 3.25.76** ([GHSA-mrhx-c7xc-m3w5](https://github.com/advisories/GHSA-mrhx-c7xc-m3w5), HIGH): memory
  exhaustion on a very large array. It is in build and development tooling only (`@expo/cli`), and is not
  in the Android or Windows app.

## Known limitations

- Developer Preview: tested on a Samsung Galaxy S23 (Android 16) and Windows 11 x64 only. English only.
- **No macOS build.** The macOS desktop app is built in CI only, and its map has not been run on WKWebView
  with MapLibre 6.
- **iOS: downloads are not supported yet** (Maps & places shows the countries; packs are provisioned or
  imported).
- **Several countries at once** were tested on the S23 with up to 3 map packs (Cyprus, Greece and
  Japan's Kanto part) together; phones with less memory and five or more countries are not measured.
- Some parts of countries with overseas territories span areas far apart (for example France's
  Réunion with Provence): "show on map" frames the whole part.
- Emergency numbers: official sources for 35 countries only; elsewhere "112 — check the local number".
- Source excerpts are shown verbatim: a wrong or misleading sentence in a pack is shown as written.
- AI summaries can be wrong: check the cited excerpt. Emergency and medical questions get no AI summary.
- Windows installers are unsigned; no automatic updates.
